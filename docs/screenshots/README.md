# ExamAI Screenshots & Media Assets

Place your application screenshots in this directory using the following recommended filenames:

1. `admin-dashboard.png` - Admin Dashboard overview with KPIs and the Active Live Examinations widget.
2. `live-roster.png` - Live examination student roster and proctor monitoring.
3. `question-bank.png` - Question bank list with filtering, subject management, and bulk actions.
4. `faculty-generator.png` - Automated paper generator with blueprint settings and distribution charts.
5. `paper-editor.png` - Exam paper edit view with question shuffle and on-the-fly swap.
6. `student-exam.png` - Student exam interface with real-time countdown palette and autosave.
7. `student-results.png` - Exam performance analytics, scoring review, and trend charts.

These images are referenced directly in the main repository [README.md](../../README.md).
